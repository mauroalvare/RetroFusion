# Novedades de 0.3.3

- **Investigación continua para las fusiones.** El estudio vuelve a comprobar los datos
  que faltan y retoma su partida de investigación entre rondas. Conserva la misma idea,
  el juego base y los aportes elegidos.
- Si la escritura descubre otro requisito pendiente, vuelve a investigarlo y continúa
  automáticamente, sin pedir otra pulsación.
- **Tiempo orientativo antes de empezar.** La preparación, las referencias, la escritura
  y las pruebas comparten hasta una hora. El reloj conserva el tiempo total entre etapas.
- Las estimaciones pueden usar el historial local de creaciones terminadas y guardadas.
  Los trabajos cancelados, fallidos o rechazados no cuentan para ese historial.
- **Cancelación durante las comprobaciones.** También detiene los jugadores de prueba
  y libera sus controles. Los datos ya comprobados y los borradores se conservan.
- **Protección de los datos de la fusión.** Comprueba originales, perfiles y firmware
  antes de usar o guardar resultados, también cuando la idea entra directamente a crear.
  Si cambian durante el trabajo, rechaza un resultado desactualizado y conserva el borrador.

La investigación puede detenerse si no encuentra evidencia nueva o alcanza el tiempo
disponible. No garantiza descubrir todos los datos de cualquier juego. Las partidas
privadas de investigación duran mientras ese trabajo está abierto; los perfiles y los
borradores completados se guardan. El modo manual o por carpeta sigue necesitando
respuestas del chat o agente.
